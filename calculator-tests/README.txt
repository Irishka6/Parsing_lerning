# Автоматизированное тестирование геометрического калькулятора

Проект представляет собой UI-автотесты для проверки геометрических вычислений (площадь и объем фигур) на базе веб-калькулятора. Тесты написаны на Python с использованием Selenium WebDriver и фреймворка Pytest.

## 🛠 Технологии и паттерны
- **Язык:** Python 3
- **Библиотеки:** Selenium WebDriver, Pytest, pytest-xdist (для параллельного запуска)
- **Паттерны проектирования:**
  - **Page Object Model (POM):** Строгое разделение локаторов, бизнес-логики и самих тестов.
  - **Data-Driven Testing (DDT):** Тестовые сценарии и ожидаемые результаты вынесены во внешний JSON-файл.

## 📂 Структура проекта
- `pages/percent_calculator_page.py` — базовый класс Page Object. Содержит только URL, локаторы (отдельно от методов) и атомарные методы для взаимодействия с элементами (клик по цифрам, знакам)[cite: 3].
- `pages/base_page.py` — класс `GeometryCalculator`, наследующий базовую страницу. Содержит бизнес-логику (последовательности кликов) для вычисления формул конкретных фигур (например, `circle_area`, `cylinder_volume`)[cite: 2].
- `tests/test_percent_calculator.py` — файл с тестами. Не содержит локаторов (`By.`), явных ожиданий (`WebDriverWait`) или технических команд Selenium. Взаимодействует со страницей только через методы Page Object.
- `data/percent_cases.json` — набор тестовых данных. Позволяет добавлять новые проверки без изменения кода тестов[cite: 4].

## 🧪 Покрытые сценарии (Тестовые данные)
Проект поддерживает проверку следующих фигур (задаются через `percent_cases.json`):
1. **Square Area** — Площадь квадрата ($S = a^2$)
2. **Rectangle Area** — Площадь прямоугольника ($S = a \cdot b$)
3. **Circle Area** — Площадь круга ($S = \pi \cdot r^2$)
4. **Cube Volume** — Объем куба ($V = a^3$)
5. **Box Volume** — Объем прямоугольного параллелепипеда ($V = a \cdot b \cdot c$)
6. **Cylinder Volume** — Объем цилиндра ($V = \pi \cdot r^2 \cdot h$)

*Тесты поддерживают проверку дробных чисел, умеют игнорировать разницу локалей (точка/запятая) и используют "умное" сравнение чисел с плавающей точкой (допускается микро-погрешность при округлении).*
